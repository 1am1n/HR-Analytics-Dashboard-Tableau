# 📊 Project Overview

The **HR Analytics Dashboard** is an interactive business intelligence project developed using **Tableau** to analyze workforce data and generate actionable HR insights.

This dashboard enables organizations to monitor key HR metrics such as employee distribution, attrition trends, workforce demographics, departmental performance, and employee retention patterns through dynamic visualizations and KPI tracking.

The project demonstrates practical skills in:

* Data Visualization
* Business Intelligence
* HR Analytics
* KPI Reporting
* Dashboard Development
* Workforce Analysis

# 🎯 Objectives

* Analyze employee demographics and workforce distribution
* Track employee attrition and retention patterns
* Monitor HR KPIs and workforce metrics
* Identify trends affecting employee performance
* Support data-driven HR decision-making
